# Student Management System

## Project Description

This is a Python console-based Student Management System developed as a portfolio project. The application allows an administrator to manage student records by adding, viewing, searching, updating, and deleting student information.

The purpose of this project is to strengthen my understanding of Python programming, problem solving, file handling, and software design.

---

## Features (Version 1)

- Add a new student
- View all students
- Search for a student
- Update student information
- Delete a student
- Save student data
- Load student data

---

## Student Information

Each student record contains:

- Student ID
- Name
- Age
- Department
- Marks

---

## Rules

- Every Student ID must be unique.
- Age must be greater than 0.
- Marks must be between 0 and 100.
- Name cannot be empty.
